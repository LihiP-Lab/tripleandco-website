# Triple & Co. · Website Concept v2 (DRAFT)

Alternative website concept for tripleandco.com. **Not published, not linked to the live site.**

## How to view

Double-click any file to open it in a browser. Start with `index.html`. All five pages link to each other. Images load from the existing `public/images/` folder in this repo, so keep this folder inside the website folder.

## Pages

- `index.html`: Homepage. New keyword-led hero, agent cast panel, stat strip, three-pillar explainer, 9-service grid, AI preview band, process, Lihi trust section, comparison proof, final CTA.
- `services.html`: All 9 services with Who it's for / The problem / The outcome framing, deliverables, jump nav, and a mid-page lead capture band.
- `ai-experience.html`: The new AI area. Animated command-center hero, 8-agent grid, Brief-Run-Deliver flow, 4 real use cases, 3 starter workflows (Diagnostic, Content Engine, Launch Team), benefits band, Human in the Loop, and three "Triple Labs" placeholders for future interactive tools (chat demo, ROI calculator, diagnostic quiz).
- `about.html`: Story-driven About with stats, why-trust section, team band, working principles, CTA.
- `contact.html`: Conversion-focused form (name, email, company, project type, timing, message) with a "what happens next" sequence and a working confirmation state. Form is front-end only; no backend wired yet.

## Conversion system

- Primary CTA everywhere: **Book a Consultation**
- Secondary CTA: **Explore AI Solutions**
- Lead capture on home, services, AI, and contact pages
- Trust: $70M+ raised, 15+ years, tripled revenue twice, press logos, human-review guarantee

## Notes

- Built with the Triple & Co. brand book: Inter, pink #FE3465 / purple #896D9C / dark #1B161F, 5px gradient top bar on every card, pink-to-purple gradient hero words, dark hero with radial pink glow.
- No em dashes, no banned jargon, voice rules applied.
- Heads up: this folder lives inside the website repo. It will not appear on the live site, but the `deploy` alias would push it to the public GitHub repo. Move it elsewhere first if you want to keep the concept private.
